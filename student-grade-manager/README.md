# Student Grade Manager

A beginner-friendly Java console application for managing student marks, calculating averages, assigning grades, searching student records, and saving data to a local file.

## Features

- Add student records
- Enter marks for multiple subjects
- Calculate average and percentage
- Automatically assign grades
- Search for students by roll number
- Display all students
- Save records to a text file
- Load saved records when the program starts
- Basic input validation and exception handling

## Concepts Demonstrated

- Java classes and objects
- Encapsulation
- ArrayList collections
- Methods and control flow
- File handling
- Exception handling
- Basic OOP design

## How to Run

```bash
javac StudentGradeManager.java
java StudentGradeManager
```

The application stores records in `students.txt` in the project directory.
